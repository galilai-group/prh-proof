# Data

Every dataset lives in `data/<name>` inside the repository, as a folder or a symbolic link to an existing copy,
unless an environment variable points elsewhere (`prh/data.py`). Only Flickr30k is needed for the quick start.

| folder (variable) | dataset | expected layout |
|---|---|---|
| `data/flickr30k` (`PRH_FLICKR`) | Flickr30k, Karpathy split: 29k train, 1,014 val, 1,000 test images, five captions each | `flickr_annotations_30k.csv` (`filename`, `img_id`, `split`, `raw` = JSON list of captions), `flickr30k-images/` |
| `data/` (`PRH_COCO`) | COCO Karpathy train and restval captions (text only); STS-B test | `coco_{train,restval}.parquet` (`sentences`), `stsb_test.parquet` |
| `data/coco5k` (`PRH_COCO5K`) | COCO Karpathy test split, 5,000 images | `test_5k_mscoco_2014.csv` (`filename`, `cocoid`, `raw`), `images_mscoco_2014_5k_test/` |
| `data/recap` (`PRH_RECAP`) | Recap-DataComp-1B: alt-text and two LLaVA-LLaMA-3 recaptions per web image | `data/train_data/train-*.parquet` (texts), `images/recap_datacomp_1b_*.tar` (WebDataset shards, `.jpg` + `.json`) |
| `data/msrvtt` (`PRH_MSRVTT`) | MSR-VTT: 10k clips, 20 captions each; train 7,010, val the other 1,990 clips of the 9k split, test 1,000 (JSFUSION) | `videos/*.mp4`, `annotations/` (`MSRVTT_data.json`, `MSRVTT_train.{7k,9k}.csv`, `MSRVTT_JSFUSION_test.csv`) |
| `data/msrvtt_frames` (`PRH_FRAMES`) | 8 evenly spaced frames per MSR-VTT clip | `<video_id>/<k>.jpg`, written by `python -m prh.data frames` (`pip install -e ".[video]"`) |
| `data/imagenet` (`PRH_IMAGENET`) | ImageNet-1k | `datasets.save_to_disk` folder with a `train` split |
| `data/rosetta` | the stored embeddings of Schnaus et al. (COCO 2014 DINOv2-B, CIFAR-10/100, ImageNet-100, their text encoders) and the COCO 2014 caption annotations | written by `python -m prh.data rosetta` (`pip install -e ".[pairfree]"`) |

```bash
python -m prh.data                      # COCO Karpathy captions and STS-B into data/ (small, text only)
huggingface-cli download nlphuji/flickr30k --repo-type dataset --local-dir data/flickr30k
(cd data/flickr30k && unzip -q flickr30k-images.zip)
huggingface-cli download nlphuji/mscoco_2014_5k_test_image_text_retrieval --repo-type dataset --local-dir data/coco5k
(cd data/coco5k && unzip -q images_mscoco_2014_5k_test.zip)
huggingface-cli download UCSC-VLAA/Recap-DataComp-1B --repo-type dataset --local-dir data/recap --include "data/train_data/*"
ln -s /path/to/your/imagenet-1k data/imagenet   # any existing copy works the same way
python -m prh.data rosetta                    # alignment without pairs (37 GB; `rosetta no-qwen`: 1.7 GB)
```

Recap's images are not distributed with the dataset: fetch them from its URLs (for example with `img2dataset`,
WebDataset output) into `data/recap/images/`. The WIT-1024 pairs of the PRH paper are loaded with
`datasets.load_dataset("minhuh/prh", revision="wit_1024")`.

Text-only Recap runs (`--data recaptext:<n>`) read the first `n` parquet files (about 203k images each, about
0.3 GB of memory per file) and need no images. Image runs on Recap (`--data recap:<n>`) index the byte offsets of
the first `n` tar shards once, in parallel, and cache the index in `runs/`.

`python -m prh.data paraphrase <file index>` writes text-only paraphrases of one Recap file's alt-texts
(Qwen2.5-7B-Instruct, no image) into `data/recap_paraphrase/` (`PRH_RECAP_PARAPHRASE`), for `--data
recaptext-altpara:<n>`; `python -m prh.data overlap` finds the WIT-1024 captions and Flickr30k photos among the Recap
training data.

Recap's recaptions are generated by an image captioner, so its text views carry information distilled from
image-text training (paper, Sec. 6); the Flickr and COCO views are human captions of the same image.
